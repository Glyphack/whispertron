This is a fork of [whispertron](https://github.com/lynaghk/whispertron).

My goal was to add better experience for using it with languages other than English.

## Install

With [mise](https://mise.jdx.dev):

```sh
mise use -g "github:Glyphack/whispertron"
```

Then start it with `whispertron`.

Or grab the built application from the releases.

Or build the app using the `./build.sh` script.
